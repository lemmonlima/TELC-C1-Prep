# 🚀 Quick Start - Mejoras Móviles Ether

¿Sin tiempo? Esta es la versión express:

## Paso 1: Agregar CSS (Obligatorio)

Agrega esta línea **después** de `<link rel="stylesheet" href="/styles.css">` en:
- `docs/woerter/index.html`
- `docs/woerter/solo.html`
- `docs/grammatik/verben-mit-praepositionen/index.html`
- `docs/grammatik/verben-mit-praepositionen/karte.html`

```html
<link rel="stylesheet" href="/styles-mobile-ether.css">
```

**O ejecuta el script automático:**
```bash
cd ~/Projects/TELC
./integrate-mobile-improvements.sh
```

## Paso 2: Probar

Abre cualquiera de esas páginas en tu teléfono. Ya deberías ver:
- ✅ Nodos más grandes (fáciles de tocar)
- ✅ Panel slide-up desde abajo
- ✅ Mejor tipografía
- ✅ Pan sin conflictos con scroll

## Paso 3 (Opcional): Gestos Avanzados

Si quieres **pinch-to-zoom** y **doble tap**, sigue las instrucciones completas en `MOBILE-ETHER-IMPROVEMENTS.md`.
